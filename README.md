# AI 論文輕鬆看 / AI Papers Made Easy — slides

YouTube 頻道「AI論文輕鬆看」與「AI Papers Made Easy」每集論文導讀的簡報（中文與英文，PowerPoint 與 PDF）。檔案放在每集的 Release，下表有連結。

Slides for each episode of the YouTube channels "AI論文輕鬆看" (Chinese) and "AI Papers Made Easy" (English), as PowerPoint and PDF. The files are attached to each episode's release, linked below.
